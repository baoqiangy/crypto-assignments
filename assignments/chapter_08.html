Diffie-Hellman Key Exchange

Basic–Moderate
IndexPrevious ExerciseNext Exercise
Why this exercise fits: Chapter 8 directly develops Diffie-Hellman and the discrete logarithm setting.

Learning Objectives

  • Compute public values from private exponents.
  • Compute a shared secret.
  • Relate the exercise to the discrete logarithm problem.

Programming Assignment

Implement a small-number Diffie-Hellman exchange. Given p, g, Alice's private value a, and Bob's private value b, compute both public values and verify that both parties obtain the same shared secret.

Requirements

  • Use fast modular exponentiation.
  • Print A=g^a mod p and B=g^b mod p.
  • Compute B^a mod p and A^b mod p.
  • Verify that the secrets match.

Example / Guidance

p=23, g=5, a=6, b=15\nA=8, B=19\nshared secret=2
