Chapter 5: More About Block Ciphers

Compare ECB and CBC Chaining with a Toy Block Cipher

Moderate
IndexPrevious ExerciseNext Exercise
Why this exercise fits: Chapter 5 is centered on block-cipher modes and initialization vectors.

Learning Objectives

  • Observe why ECB leaks repeated-block patterns.
  • Implement CBC chaining.
  • Understand the role of an IV.

Programming Assignment

Use the supplied reversible toy 8-bit block cipher E_K(x)=rotl8(x XOR K,3). Encrypt a sequence containing repeated plaintext bytes in ECB and CBC mode and compare the ciphertext patterns.

Requirements

  • Use at least 8 plaintext bytes with repeated values.
  • Implement ECB encryption.
  • Implement CBC encryption with an 8-bit IV.
  • Print plaintext, ECB ciphertext, and CBC ciphertext.
  • In a short code comment, identify why repeated plaintext values behave differently.

Example / Guidance

Plaintext contains repeated bytes such as 41 41 41 42 42 41.
