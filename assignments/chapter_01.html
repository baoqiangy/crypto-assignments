Affine Cipher and Modular Arithmetic

Basic
IndexNext Exercise
Why this exercise fits: Chapter 1 introduces modular arithmetic, the shift cipher, and the affine cipher.

Learning Objectives

  • Use arithmetic modulo 26.
  • Check whether a multiplicative key is valid.
  • Encrypt and decrypt text with the affine cipher.

Programming Assignment

Write a C++ program that encrypts and decrypts alphabetic text with the affine cipher C = (aP + b) mod 26. The program must reject a values that do not have an inverse modulo 26, preserve spaces/punctuation, and recover the original plaintext.

Requirements

  • Read a, b, and a plaintext message from the user.
  • Check gcd(a,26)=1.
  • Compute the modular inverse of a.
  • Encrypt and then decrypt the message.
  • Preserve letter case if practical; otherwise convert consistently to uppercase.

Example / Guidance

Key: a=5, b=8\nPlaintext: HELLO WORLD\nCiphertext: RCLLA OAPLX\nRecovered: HELLO WORLD
