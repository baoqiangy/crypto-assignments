Chapter 11: Hash Functions

Birthday-Collision Experiment with a Truncated Hash

Moderate
IndexPrevious ExerciseNext Exercise
Why this exercise fits: Chapter 11 explicitly covers collision resistance and the birthday attack.

Learning Objectives

  • Simulate the birthday effect.
  • Measure collisions in a small hash space.
  • Relate observed results to about 2^(n/2) work.

Programming Assignment

Use std::hash<string> only as a convenient deterministic source, then truncate its output to 16 bits. Generate random strings until two different strings have the same 16-bit value. Repeat multiple trials and report the average number of inputs needed.

Requirements

  • Run at least 20 trials.
  • Use a 16-bit truncation.
  • Ensure a collision is between two different strings.
  • Report each trial count and the average.
  • Explain in a code comment why this is a simulation, not a secure hash implementation.

Example / Guidance

For a 16-bit space, collisions should often appear after a few hundred random inputs.
