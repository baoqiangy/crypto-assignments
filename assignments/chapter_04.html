Why this exercise fits: Chapter 4 emphasizes Galois-field arithmetic and the AES diffusion layer.

Learning Objectives

  • Multiply bytes in GF(2^8).
  • Apply the AES MixColumns transformation to one column.
  • Connect field arithmetic to AES diffusion.

Programming Assignment

Implement AES byte multiplication in GF(2^8) using the AES irreducible polynomial. Use it to transform one 4-byte column with the standard MixColumns matrix.

Requirements

  • Implement xtime() and general byte multiplication.
  • Read four hexadecimal bytes.
  • Apply the standard AES MixColumns matrix.
  • Print the resulting four bytes in hexadecimal.

Example / Guidance

Input column: DB 13 53 45\nOutput column: 8E 4D A1 BC
