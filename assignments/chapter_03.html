Chapter 3: The Data Encryption Standard (DES) and Alternatives

One DES-Style Feistel Round

Moderate
IndexPrevious ExerciseNext Exercise
Why this exercise fits: A complete DES implementation is too large for this exercise, but one Feistel round directly reinforces DES structure and the f function.

Learning Objectives

  • Split a block into left/right halves.
  • Apply a round function and XOR.
  • Reverse one Feistel round.

Programming Assignment

Implement one educational DES-style Feistel round on a 16-bit block using two 8-bit halves. Use the supplied toy round function F(R,K)=rotl8(R,1) XOR K. Show that the round can be reversed.

Requirements

  • Read a 16-bit plaintext block and an 8-bit round key in hexadecimal.
  • Split the block into L and R.
  • Compute L1=R and R1=L XOR F(R,K).
  • Implement the inverse round and recover the original block.
  • Print all values in hexadecimal.

Example / Guidance

Plaintext block: 1234\nRound key: 3A\nAfter one round: 3440\nRecovered: 1234
