Chapter 14: Key Management

Password-Based Key Derivation with PBKDF2

Moderate
IndexPrevious Exercise
Why this exercise fits: Chapter 14 begins with key derivation and practical key-management concerns.

Learning Objectives

  • Derive a key from a password and salt.
  • Understand iteration count and salt roles.
  • Compare derived keys when the salt changes.

Programming Assignment

Using OpenSSL PBKDF2-HMAC-SHA256, derive a 256-bit key from a password, salt, and iteration count. Derive again with a different salt and compare the outputs.

Requirements

  • Read a password and salt.
  • Use PBKDF2-HMAC-SHA256.
  • Use an instructor-specified iteration count of at least 100000 for the exercise.
  • Derive 32 bytes.
  • Print derived keys in hexadecimal and show that changing the salt changes the result.

Example / Guidance

Compile with: g++ -std=c++17 chapter14_pbkdf2.cpp -lcrypto
