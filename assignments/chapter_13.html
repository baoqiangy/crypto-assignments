Chapter 13: Message Authentication Codes (MACs)

HMAC-SHA256 Message Authentication

Moderate
IndexPrevious ExerciseNext Exercise
Why this exercise fits: Chapter 13 directly covers HMAC and message authentication.

Learning Objectives

  • Generate an HMAC with a shared secret.
  • Verify a received HMAC.
  • Observe verification failure after message modification.

Programming Assignment

Using OpenSSL, compute HMAC-SHA256 for a message and shared secret. Recompute it for verification, then alter the message and show that the tag changes.

Requirements

  • Use HMAC-SHA256 through OpenSSL.
  • Read a secret key and message.
  • Print the HMAC in hexadecimal.
  • Verify the original message.
  • Modify one character and demonstrate that verification fails.

Example / Guidance

Compile with: g++ -std=c++17 chapter13_hmac.cpp -lcrypto
