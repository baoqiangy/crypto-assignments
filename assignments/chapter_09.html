Elliptic-Curve Point Addition over a Prime Field

Moderate
IndexPrevious ExerciseNext Exercise
Why this exercise fits: Chapter 9 centers on elliptic-curve group operations before ECDH.

Learning Objectives

  • Represent points over GF(p).
  • Implement point addition and doubling.
  • Compute small scalar multiples kP.

Programming Assignment

For the curve y^2 = x^3 + ax + b mod p, implement point addition, point doubling, and scalar multiplication using double-and-add. Use small educational parameters only.

Requirements

  • Represent the point at infinity.
  • Implement modular inverse.
  • Handle P+Q, P+P, and P+(-P).
  • Compute kP for a user-supplied k.
  • Use small prime-field parameters supplied by the instructor.

Example / Guidance

Curve: y^2=x^3+2x+2 mod 17, P=(5,1), k=2\n2P=(6,3)
